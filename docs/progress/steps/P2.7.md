## Goal
`digit-4` in Lua with its own SQLite database, following the reference
behaviour of `digit-0` (ADR-0022) and passing the shared contract test
`make contract-digit-4`. Result: digit 4.

## What Was Done
- **Service `services/digit-4`** (Lua 5.4.7, cqueues, lsqlite3, luaposix,
  SQLite 3.49), scaffolded with `scripts/new-service.sh digit-4 lua`:
  - `src/digit/http.lua`: an HTTP/1.1 server written in Lua on cqueues,
    with one coroutine per connection. It supports:
    - keep-alive, with connections closed after 10 s of silence;
    - heads up to 8 KiB (431 above);
    - bodies up to 64 KiB, read and discarded, by `Content-Length` or
      chunked (413 above; 400 for ambiguous framing);
    - at most 256 connections;
    - a lingering close;
    - error codes instead of raised errors on every socket;
    - a graceful stop.
  - `src/main.lua`: configuration, start-up checks, SIGTERM and SIGINT
    through `cqueues.signal`.
  - `src/digit/api.lua` is the contract as `Api:handle(method, path)`.
    `src/digit/store.lua` holds the lsqlite3 store, the migration runner
    and the single-row read. The other modules are `src/digit/metrics.lua`,
    `src/digit/log.lua` and `src/digit/trace.lua`.
  - `migrations/0001_digit.sql`: table `digit` with the seed `4|4|5|0`.
  - `tests/digit_spec.lua`: 22 busted tests against the real migrations,
    including the HTTP transport through a connection double.
  - `tools/doc-coverage.lua`: an LDoc comment above every definition.
- **Image stages**:
  - toolchain: Alpine 3.22.2 with every package pinned;
  - lint: StyLua check, luacheck, `luac5.4 -p`;
  - test: busted;
  - doc-coverage: the coverage script plus LDoc with `--all
    --fatalwarnings`;
  - api-docs: LDoc HTML;
  - build: the sources;
  - runtime: Alpine with the interpreter and the three modules, 20.9 MB,
    UID 10001.
- **Compose**: `digit-4` on the `services` network only, 128m (the default
  for interpreted services), volume `digit-4-data`.
- **Repository**: the `lua` header type also covers `.busted`,
  `.luacheckrc` and `config.ld`; `lua` row in
  `scripts/lib/doc-definitions.psv`.
- **Documentation**: README, all ten documents of `CLAUDE.md` 6.5.5 with
  real content, API.md, ADR-0026.

## Decisions
- Lua 5.4 with an HTTP/1.1 server written in Lua on cqueues. lua-http is
  packaged for Alpine only up to Lua 5.3, so no wrapper is needed
  (ADR-0026).
- Every socket gets an error handler that returns the error code. Before
  this change, a port in use ended the process with an uncaught cqueues
  error instead of a JSON log line.
- Lingering close: the first 431 measurement was destroyed by a TCP reset
  caused by unread input.
- Documentation coverage: LDoc skips undocumented code silently, so
  `tools/doc-coverage.lua` checks every definition, and LDoc runs with
  `--fatalwarnings`.
