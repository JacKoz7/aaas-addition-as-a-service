## Goal
`contracts/proto/` with the gRPC contracts of `CLAUDE.md` section 4.3,
`buf.yaml` and `buf.gen.yaml`, code generation for Go, Rust, Haskell, OCaml,
Elixir, C#, Crystal, Zig and Python, and the CI checks `buf lint` and
`buf breaking`. Result: gRPC contracts.

## What Was Done
- **Contracts** (`contracts/proto/aaas/<service>/v1/<service>.proto`):
  `ValidatorService.Validate`, `CommutatorService.Normalize`,
  `OperatorRegistryService.Resolve`, `IdempotencyService.Claim` and
  `MarkFailed`, `SuccessorService.Next`, `CarryService.Propagate`,
  `ConsensusService.Vote`; every service, RPC, message and field documented
  with ranges and gRPC status codes. `NextRequest` and `PropagateRequest`
  carry `task_id` (the successor's call log key and the carry event need
  it; `CLAUDE.md` 4.3 updated). `operator-registry` uses the package and
  directory `operator_registry` (a package name cannot contain `-`).
- **buf workspace** `contracts/proto/buf.yaml` (lint `STANDARD` +
  `COMMENTS`, breaking `FILE`) and `buf.gen.yaml` (local plugins only,
  `clean: true`, Go managed `go_package_prefix`).
- **Tool image** `aaas/buf:dev` (`infra/buf/Dockerfile`, 838 MB): buf
  1.74.0 and the plugins built from source in per-language stages —
  protoc-gen-go v1.36.12 / protoc-gen-go-grpc v1.6.2, protoc-gen-prost /
  protoc-gen-tonic 0.5.0, proto-lens-protoc 0.9.0.1 (with the GHC
  `settings` files it reads at run time), protoc-gen-ocaml
  (ocaml-protoc-plugin 6.2.0, static), protoc-gen-elixir (protobuf 0.17.1),
  protoc + grpc_csharp_plugin (Grpc.Tools 2.84.0), protoc-gen-crystal
  (protobuf.cr 2.3.1, static), protoc-gen-zig (zig-protobuf 6.0.0, Zig
  0.16.0), grpcio-tools 1.84.0 with the adapter
  `infra/buf/protoc_gen_grpc_python.py` for grpc_python.
- **Generated code** committed in `contracts/gen/<language>/` (107 files,
  1.1 MB) with `contracts/gen/README.md` (layout, runtimes, how a service
  consumes it).
- **Commands**: `scripts/proto.sh` (lint, breaking, generate,
  check-generated); make targets `proto-lint` (part of `make lint`),
  `proto`, `proto-check`, `proto-image`. `buf breaking` compares with
  `PROTO_AGAINST` (default: merge base with `main`) extracted by
  `git archive`, and skips revisions without contracts.
- **CI** job `proto`: `make proto-lint` on every run, generated-code check
  when `contracts/proto`, `contracts/gen` or `infra/buf` changed; part of
  `ci-ok`.
- **API references**: `scripts/service-api.py` 0.2.0 generates a gRPC
  section from `contracts/proto` between `grpc` markers (successor API.md,
  API.md template, which now also has generated event markers).
- **Repository hygiene**: `contracts/gen/` excluded from pre-commit and
  doc-check, marked `linguist-generated`; doc-check knows top-level proto
  definitions; interrogate covers `infra/buf/`.
- **Documentation**: ADR-0020, amendment of ADR-0016, `contracts/proto/README.md`,
  glossary (`buf`, generated code), risk R-017 (no gRPC runtime for
  Crystal and Zig), `CLAUDE.md` 4.3, 5 and 9.3.
- **Re-plan of `TEMPORARY(P2.1)`** (decided with the user): the gRPC
  server `Next` moves to P2.13, the HTTP `POST /v1/next` stays for the
  ledger until P3.3; markers in successor and ledger are now
  `TEMPORARY(P3.3)`; P2.13 and P3.3 rows updated in `CLAUDE.md` and
  `docs/PROGRESS.md`.
