## Goal
The HTTP/JSON contract of the ten digit services (`CLAUDE.md` 4.4) as an
OpenAPI document `contracts/http/digit.yaml`, and one contract test,
`tests/contract/digit.sh`, that every digit service (P2.3–P2.12) must pass.
Result: the digit contract.

## What Was Done
- **`contracts/http/digit.yaml`** (OpenAPI 3.1, contract 1.0.0): `GET /value`
  → `DigitValue`, `GET /next` → `DigitNext` (`carry` only for 9),
  `GET /health` → `Health` with `checks.database`, `GET /metrics` with the
  counter `digit_requests_total{digit, endpoint, outcome}`; closed schemas;
  optional `traceparent`; errors as problem details (404, 405 with
  `Allow: GET`, 503); `security: []` (internal network only).
- **Lint**: `contracts/http/redocly.yaml` (`recommended-strict`) and
  `make openapi-lint` (Redocly CLI 2.64.1), part of `make lint`.
- **Contract test**: `tests/contract/digit_contract.py` (8 checks, schemas
  taken from `digit.yaml`, TAP output) and the wrapper
  `tests/contract/digit.sh <d> [url]` running it in `aaas/docs-portal:dev`
  on `aaas-services`; make targets `contract-digit-<d>` and
  `contract-digits`.
- **Self-test**: `tests/contract/stub/digit_stub.py` (test double with
  injectable faults) and `tests/contract/selftest.sh` (3 conforming and 2
  faulty doubles); `make contract-selftest`.
- **CI**: job `contracts` runs `make openapi-lint` and
  `make contract-selftest`.
- **API references**: `scripts/service-api.py` 0.3.0 generates the HTTP
  section from the component's OpenAPI document between `http` markers;
  the API.md template now generates HTTP, gRPC and events sections.
- **Documentation**: ADR-0021, `contracts/http/README.md`,
  `tests/contract/README.md`, `CLAUDE.md` 4.4, glossary (contract test,
  digit service); interrogate and doctests cover `tests/contract/`.

## Decisions
- ADR-0021: one OpenAPI 3.1 document for all ten services, a shared
  counter name instead of per-service prefixes, `security: []`, Redocly
  `recommended-strict`, a black-box Python test validated by the
  document's own schemas, and a self-test against test doubles.
