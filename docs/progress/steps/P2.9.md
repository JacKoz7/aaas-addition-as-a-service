## Goal
`digit-6` in Swift with its own SQLite database, following the reference
behaviour of `digit-0` (ADR-0022) and passing the shared contract test
`make contract-digit-6`. Result: digit 6.

## What Was Done
- **Service `services/digit-6`** (Swift 6.3.3, no package dependencies,
  SQLite 3.45 through its C API), scaffolded with
  `scripts/new-service.sh digit-6 swift`, with targets in `src/` and
  `tests/`:
  - `src/DigitService/Server.swift`: an HTTP/1.1 server on POSIX sockets,
    with one detached thread per connection (256 KiB stack). It supports
    keep-alive with a 10 s receive timeout, heads up to 8 KiB (431 above),
    bodies up to 64 KiB (413 above, answered at once; 400 for ambiguous
    framing), at most 256 connections, and a lingering close capped at
    16 KiB. The contract is called under one `Synchronization.Mutex`.
  - `src/digit6/main.swift`: configuration, start-up checks, and SIGTERM
    and SIGINT through `sigwait`.
  - `src/DigitService/Api.swift`, `src/DigitService/Store.swift`,
    `src/DigitService/Metrics.swift`, `src/DigitService/Log.swift` (one
    `write(2)` per line) and `src/DigitService/Trace.swift`.
  - `src/CSQLite`: the SQLite system library module.
  - `migrations/0001_digit.sql`: table `digit` with the seed `6|6|7|0`.
  - `tests/DigitServiceTests/DigitTests.swift`: 23 swift-testing tests.
  - `tools/doc-coverage.swift`: a doc comment on every symbol of the
    compiler's symbol graphs, down to private access.
- **Image stages**:
  - toolchain: `swift:6.3.3-noble` and `libsqlite3-dev`, pinned;
  - lint: `swift format lint --strict`, and a build with warnings as
    errors;
  - test: `swift test`;
  - doc-coverage: the symbol graph check and DocC with
    `--warnings-as-errors`;
  - api-docs: DocC static HTML with the portal's base path `api/digit-6`
    and a root redirect;
  - build: `--static-swift-stdlib`;
  - runtime: distroless cc-debian13 plus SQLite and busybox `wget`;
    70.4 MB, UID 10001.
- **Compose**: `digit-6` on the `services` network only, 64m, exec-form
  healthcheck, volume `digit-6-data`.
- **Repository**: a `swiftpm` header type (the `// swift-tools-version:`
  line as its preamble); `module.modulemap` files use the swift style.
- **Documentation**: README, all ten documents of `CLAUDE.md` 6.5.5 with
  real content, API.md, ADR-0028.

## Decisions
- No SwiftNIO. Cloning it (86 000 git objects) broke off after 16 minutes
  on the 30–100 KB/s network, and every Docker rebuild would clone it
  again. The service uses its own server on POSIX sockets and has no
  package dependencies (ADR-0028).
- One thread per connection, and the contract under one mutex. The
  classes holding the store and the metrics are `@unchecked Sendable`.
- Documentation coverage is checked on the compiler's symbol graphs, down
  to private access. Synthesized symbols and implicit initializers are
  exempt.
- DocC is exported with the portal's hosting base path and a root
  redirect.
