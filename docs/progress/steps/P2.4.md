## Goal
`digit-1` in C++ with its own SQLite database, following the reference
behaviour of `digit-0` (ADR-0022) and passing the shared contract test
`make contract-digit-1`. Result: digit 1.

## What Was Done
- **Service `services/digit-1`** (C++20, g++ 14, cpp-httplib 0.26.0,
  nlohmann-json 3.11.3, SQLite 3.49.2), scaffolded with
  `scripts/new-service.sh digit-1 cpp`:
  - `src/api.cpp`: `Api::handle(method, path) → Reply`, the contract free
    of the server library: `/value`, `/next`, `/health`, `/metrics`,
    problem details for 404, 405 (`Allow: GET`) and 503; the row is read on
    every request (under one mutex) and must name `AAAS_DIGIT`;
  - `src/store.cpp`: SQLite in RAII (connection, statements), migration
    runner with `schema_migrations`, read of the single `digit` row,
    `StoreError`;
  - `src/metrics.cpp` (atomic counters), `src/log.cpp` (JSON lines with
    nlohmann-json), `src/trace.cpp` (`traceparent`);
  - `src/main.cpp`: configuration, start-up checks, cpp-httplib with four
    worker threads, catch-all routes on every routed method, an error
    handler that turns the library's own errors into problem details,
    TCP_NODELAY, SIGTERM shutdown;
  - `migrations/0001_digit.sql`: table `digit` with the seed `1|1|2|0`;
  - `tests/test_digit.cpp`: doctest, 9 test cases, 60 assertions against
    the real migrations, including the proof that answers follow the row.
- **Image stages**: toolchain (Alpine 3.22.2, all packages pinned,
  `httplib.h` added with `ADD --checksum`), lint (clang-format, clang-tidy
  with every finding an error, g++ `-Werror -Wconversion -Wshadow`), test,
  doc-coverage (Doxygen, private members and anonymous namespaces
  included), api-docs, build, runtime (20.6 MB, UID 10001).
- **Compose**: `digit-1` on the `services` network only, volume
  `digit-1-data`, no database password (the scaffold's password and `data`
  network removed, as for `digit-0`).
- **Documentation**: README, all ten documents of `CLAUDE.md` 6.5.5 with
  real content, API.md (HTTP section generated from `digit.yaml`), ADR-0023.

## Decisions
- ADR-0023: cpp-httplib 0.26.0 verified by SHA-256 (Alpine has no C++ HTTP
  server package), four worker threads sharing the SQLite connection under
  a mutex, TCP_NODELAY (without it every keep-alive call took about 40 ms),
  catch-all routes instead of a pre-routing handler (an unread body broke
  the next request on the connection), two documented answers outside the
  contract (413 for a body above 1 KiB, 400 for a non-HTTP method name),
  doctest, Doxygen with `EXTRACT_PRIVATE` and `EXTRACT_ANON_NSPACES`.
