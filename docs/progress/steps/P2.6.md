## Goal
`digit-3` in Free Pascal with its own SQLite database, following the
reference behaviour of `digit-0` (ADR-0022) and passing the shared contract
test `make contract-digit-3`. Result: digit 3.

## What Was Done
- **Service `services/digit-3`** (Free Pascal 3.2.2, objfpc, fcl-web,
  SQLite 3.46), scaffolded with `scripts/new-service.sh digit-3 pascal`:
  - `src/DigitService.pas`: configuration, start-up checks, the fcl-web
    `TFPHttpServer` (one thread per connection, 2 s socket read timeout,
    bodies above 64 KiB not read and answered 413, unknown headers kept for
    `traceparent`), SIGTERM through `AcceptIdleTimeout`, waiting for
    running connections;
  - `src/DigitApi.pas`: the contract as `TApi.Handle(method, path)` with a
    lock around the SQLite connection; `src/DigitStore.pas`: `sqlite3`
    unit, migration runner, single-row read, `EStoreError`;
    `src/DigitMetrics.pas` (interlocked counters), `src/DigitLog.pas`,
    `src/DigitTrace.pas`, `src/digit3.lpr`;
  - `migrations/0001_digit.sql`: table `digit` with the seed `3|3|4|0`;
  - `tests/TestDigit.pas` and `tests/testrunner.lpr`: 8 fpcunit tests
    against the real migrations.
- **Image stages**: `pasfmt` (pasfmt 0.7.0 built from its release commit),
  toolchain (Debian trixie, Free Pascal, PasDoc, xmlstarlet, SQLite,
  libgcc start files, all pinned), lint (pasfmt check; fpc with warnings,
  notes and hints as errors), test, doc-coverage (PasDoc simplexml checked
  by xmlstarlet plus `tools/implementation-doc-check.awk`), api-docs
  (PasDoc HTML), build, runtime (distroless cc-debian13 pinned by digest,
  SQLite library, static busybox as wget; 60 MB, UID 10001).
- **Compose**: `digit-3` on the `services` network only, exec-form
  healthcheck (no shell in the image), volume `digit-3-data`.
- **Repository**: header style for `.awk` files; `pascal` row in
  `scripts/lib/doc-definitions.psv`.
- **Documentation**: README, all ten documents of `CLAUDE.md` 6.5.5 with
  real content, API.md, ADR-0025.

## Decisions
- ADR-0025: Debian toolchain (Alpine has no Free Pascal), fcl-web
  `TFPHttpServer` threaded with a read timeout and a body cap,
  `ContentStream` for exact bodies, pasfmt instead of ptop (ptop breaks
  classes), compiler as linter, PasDoc simplexml plus an awk check as the
  coverage gate, fpcunit, distroless cc runtime with an exec healthcheck.
