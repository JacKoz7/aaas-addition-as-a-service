## Decisions
- The service has its own HTTP/1.1 server on `dart:io` sockets instead of
  `HttpServer`. `HttpServer` buffers request heads up to 1 MiB (OOM kill)
  and delays 413 until the body arrives (ADR-0027).
- The lingering close is capped at 16 KiB. Uncapped, a flood allocated
  faster than the garbage collector freed it and the service was killed
  again.
- sqlite3 loads the system SQLite (`source: system`), so the build
  downloads no binary. The executable is built with `dart build cli`,
  because `dart compile exe` refuses build hooks.
- Documentation coverage uses package:analyzer for every declaration. The
  lint covers public members only, and dartdoc does not fail on missing
  comments.
